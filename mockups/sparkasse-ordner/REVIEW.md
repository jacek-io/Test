Inputs: design ticket, client requirements catalogue, client's clickable HTML prototype, screenshots of the live
Voranalyse and Fondsmatrix tabs. Feeds FC-1149. Reviewed internally by PM and tech lead.

**Decision: folder path button + Miller-column popover** (formerly "Variant C"). The sidebar and drawer directions

## Interaction rules (board V7)

- The path button sits where "FCR Peergroup" sits today: "Folders" · breadcrumb of the selection · fund count · ×.
  With nothing selected it reads "Folders · All funds · 10,553".
- Clicking a folder selects it, filters the table immediately and opens the next column. Any level can be selected.
  There is no separate "open" gesture: the next column is the opened folder; chevrons mark folders with children.
- "All funds" is the first entry of column 1 and clears the selection. "Clear selection", "Done", Esc or a click
  outside close the popover; the selection stays and persists per user and tab.
- Search filters all levels and switches to a flat hit list with the path under each hit; ↵ selects the first hit.
- Counts include subfolders and follow the LVS/IVV switches and the fund-company filter, not the text search.
  Empty folders stay visible (0, dimmed).
- ETF peer groups sit only under the ETF top folder; below it the same two levels apply with the prefix stripped.

## Answers the ticket asked for

- **Popover search replaces "FCR Peergroup"**: yes, the button takes its spot; same 206 entries plus path and count.
  "Nur ETFs" goes (ETF top folder), "Anlageklasse" goes (catalogue). "Fund company" and "Filter" stay. Open with the
  client: the popover search finds peer groups, not funds.
- **Fondsmatrix**: same button and popover with two levels; "No asset class" as a dimmed entry at the bottom of
  column 1 so no fund drops out. Export button label carries the folder because FC-1149 exports only the open folder.
- **Switches**: one group "Investable for LVS | IVV" in both tabs, after the fund-company filter (Voranalyse) or after
  the folder button (Fondsmatrix). Replaces "Nur investierbare Fonds". Result line above the table names the state.

## FC-1149 touchpoints (flagged, none blocking)

- IVV column and red stripe fit into the full-width table (S2); the name column shrinks from 330 to 300 px.
- Fondsmatrix on one page and Stammdaten always open: no interaction with the popover.
- Fund name link to the Voranalyse should land with the fund's folder pre-selected in the path button.

## Assumptions to confirm

1. Folder rule applied mechanically (first word / first two words) on live peer group names; yields folders such as
   "Renten RMB" and "Aktien Branche" (12 peer groups). If the Analyst Tool has a curated level 2, use that.
2. ETF peer groups carry the prefix "ETF".
3. Sample data: 10,553 funds in 133 peer groups; the client's prototype states 12,029 in 206.
