# Sparkasse Leipzig – folder panel for Voranalyse and Fondsmatrix

Inputs: ticket (folder panel design), requirements catalogue (client), client's clickable HTML prototype,
screenshots of the live Voranalyse and Fondsmatrix tabs. Feeds FC-1149.

Mockups: canvas with 12 artboards generated by `build.mjs` (`node build.mjs`, output in `out/`).
Pages: **Übersicht** (decision matrix, FCR Peergroup answer, assumptions, FC-1149 touchpoints),
**Variante A · Seitenleiste**, **Variante B · Drawer**, **Variante C · Ordnerpfad**, **Fondsmatrix · Schalter · FC-1149**.

## Variants (Voranalyse layout)

| | A · Sidebar (recommended) | B · Drawer | C · Folder path |
|---|---|---|---|
| Position | 300 px panel left of the table, in the layout; collapses to a 48 px rail | 380 px drawer slides over the table on demand | No panel; a breadcrumb button in the filter bar opens a 3-column popover |
| Table readability | 1044 px instead of 1360 px, no horizontal scroll; name column wraps to 2 lines | Full width, but hidden while browsing | Always full width |
| Selection when closed | Path chip with × in the "Aktuelle Auswahl" line + dot on the rail | The "Ordner" button carries path, count and × | The breadcrumb button is the display |
| When to pick | Client asked for a permanent folder navigation | Fallback below ~1280 px (A behaves like B there) | Only if the client does not want the tree permanently visible |

Shared in all variants (board A4): "Alle Fonds" first, chevron opens, name selects (any level), counts per folder
following the LVS/IVV switches and Fondsgesellschaft filter (not the text search), panel search filters the tree and
expands hits, ETF as its own top folder with the same two sub-levels.

## Answers the ticket asked for

- **Panel search replaces "FCR Peergroup"**: yes. Same 206 entries, plus path and count. Keeping both means two ways
  to the same selection. "Nur ETFs" goes too (ETF top folder), "Anlageklasse" goes per the catalogue.
  "Fondsgesellschaft" and "Filter" stay. Open with the client: the panel search finds peer groups, not funds.
- **Fondsmatrix**: same panel, two levels (Assetklasse › Sub-Assetklasse), "Ohne Assetklasse" as last entry so no
  fund drops out of the tree. Export button shows the selection ("Exportieren · Aktien › Europa · 14") because FC-1149
  exports only the open folder.
- **Switches**: one group "Investierbar für LVS | IVV" in both tabs, right of Fondsgesellschaft (Voranalyse) or next
  to the search (Fondsmatrix). Replaces "Nur investierbare Fonds". Result line above the table spells out the state;
  both on = intersection. Board G2 shows all four states.

## FC-1149 touchpoints (flagged, not blocking)

- IVV column and red stripe fit into the 1044 px table (board G3); the name column shrinks to ~240 px and wraps.
  Alternative: move "Handlungsempfehlung" into the expanded detail.
- Fondsmatrix all on one page + Stammdaten always open: table grows; the panel takes 300 px. Horizontal scroll
  (top and bottom) is planned anyway.
- Fund name link to Voranalyse should open the fund's folder there.

## Assumptions to confirm

1. Folder rule applied mechanically (first word / first two words) on live peer group names. Produces folders such as
   "Renten RMB" and "Aktien Branche" (12 peer groups). If the Analyst Tool has a curated level 2, use that.
2. ETF peer groups carry the prefix "ETF"; levels 2 and 3 under the ETF folder ignore the prefix.
3. Counts follow switches and the Fondsgesellschaft filter, not the text search. Empty folders stay visible (0, dimmed).
4. One selection at a time; selection and panel state persist per user and tab.
5. Sample data: 10,553 funds in 133 peer groups in the mockups; the client's prototype states 12,029 in 206.
